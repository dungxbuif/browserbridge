# User Stories

- US-001: Là owner, tôi cấu hình server/token một lần để Chrome restart xong extension tự online.
- US-002: Là owner, tôi bật một công tắc để agent điều khiển mọi web tab và tắt ngay khi muốn dừng.
- US-003: Là agent, tôi quản lý tab/window, điều hướng và quan sát trang để biết trạng thái hiện tại.
- US-004: Là agent, tôi click/type/key/scroll/drag/select/evaluate để hoàn thành tác vụ như người dùng.
- US-005: Là agent, tôi nhận event và structured error để phục hồi khi tab đổi, timeout hoặc target bị Chrome chặn.
- US-006: Là owner, tôi chạy MCP client để giao việc cho agent mà không cần local bridge phụ.
- US-007: Là owner, tôi hỏi agent đã collect bao nhiêu user, media nào lỗi, lỗi nằm ở component/stage nào và worker đang chạy thế nào mà không cần đọc SQL/log thủ công.
- US-011: Là owner, tôi cho agent dùng typed MCP tools và optional workflow skill mà không đặt API/session/provider key trong skill hoặc tool argument.
- US-008: Là owner, tôi yêu cầu agent trigger/retry/cancel crawl job có permission và audit rõ ràng.
- US-009: Là owner, tôi collect media từ TikTok, Instagram và Facebook bằng browser session, retry lỗi có giới hạn, và tracking từng file trong một Drive folder cố định.
- US-010: Là owner, tôi ra lệnh cho agent gửi một media qua mlem và hỏi ai Like/Che hoặc media nào đã archive mà không trao raw Mezon/Drive credential cho agent.
