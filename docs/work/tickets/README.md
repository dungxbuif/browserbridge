# Tickets

Use this folder for feature, task, refactor, and documentation work.

## Naming

Use:

```text
TICKET-<id>-<short-name>.md
```

Example:

```text
TICKET-001-add-agent-gateway.md
```

## Execution Rules

- Small tickets may auto-run only under the policy in `AGENTS.md`.
- Non-small tickets require a detail design before implementation.
- Every completed ticket needs verification evidence and docs reconciliation.

Start from `docs/templates/TICKET.md`.
