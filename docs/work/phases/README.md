# Phases

Use this folder for multi-ticket work packages.

## Naming

Use:

```text
PHASE-<id>-<short-name>.md
```

Example:

```text
PHASE-001-framework-scaffold.md
```

## Required Content

Each phase must include:

- Goal
- Scope
- Out of scope
- Tickets and bugs
- Dependencies
- Risks
- Success criteria
- Verification plan
- Completion summary

Start from `docs/templates/PHASE.md`.
