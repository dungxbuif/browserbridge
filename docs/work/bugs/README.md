# Bugs

Use this folder for defects, incidents, regressions, and production issues.

## Naming

Use:

```text
BUG-<id>-<short-name>.md
```

Example:

```text
BUG-001-login-session-expiry.md
```

## Bug Rules

- Bugs must include reproduction steps before implementation.
- Detail design must include root cause, impact scope, and regression plan.
- Verification must cover both the direct fix and impacted behavior.

Start from `docs/templates/BUG.md`.
